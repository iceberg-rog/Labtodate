## Files changed

### `nginx/lab2date.conf` — BUG-015 (RSC `_rsc` prefetch 503 under burst)
- Added http-context `upstream lab2date_web { server 127.0.0.1:3100; keepalive 64; }`.
- Added `map $http_upgrade $connection_upgrade { default upgrade; '' ""; }`.
- Both server blocks: `location /` now proxies to `http://lab2date_web` and sends
  `Connection $connection_upgrade` instead of a hardcoded `Connection "upgrade"`.
- Effect: concurrent server-component renders reuse a pool of up to 64 kept-alive
  upstream connections instead of opening (and exhausting) a fresh connection per
  request; websocket upgrades still pass through unchanged.
- **Action required before reload on host:** run `nginx -t` (nginx binary was not
  available in the build sandbox, so syntax was validated only by brace balance
  and manual review). Optionally also run 2-4 web replicas for extra headroom.

### `docker-compose.yml` — BUG-016 (blog cover images 403)
- `minio-init` service: added
  `mc anonymous set download "local/$S3_BUCKET/blog-cover";` alongside the
  existing `products` grant. Covers the self-host / dev MinIO path.

### `src/lib/storage/s3.ts` — BUG-016 (authoritative bucket policy)
- `ensureBucket()` public-read policy `Resource` array now also includes
  `arn:aws:s3:::${BUCKET}/blog-cover/*`. This is re-applied on every boot and
  covers R2 / AWS / MinIO alike.
- Per-prefix and scope-tight: PRIVATE prefixes (`support-att/*`, payment `proof`
  keys) are deliberately left out — they are served only via auth-gated proxies.
